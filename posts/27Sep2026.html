在Unity中显示隐藏的UI对象

2026-09-27 · GameDev

业精于勤，荒于嬉；行成于思，毁于随。

前言

在游戏开发过程中，我们会遇到各种各样的问题。在此为了更方便地说明问题，我会假设一个场景。假如我们制作了一个敌人，但是他不能立刻显示在玩家的视角中，而是来一个JumpScare！我打算先隐藏他，然后在需要的时机唤醒他。

一、问题描述

我在场景中将这个敌人对象隐藏，给摄像机绑定一个脚本，假如他会20s后显示，我在脚本中这样写：


GameObject enemy; // 等待唤醒的敌人

void Start()
{
  enemy = GameObject.Find("Enemy"); // 场景中敌人对象的名称就是 Enemy
  Invoke("ShowEnemy",20); // 在20s后唤醒他
}

void ShowEnemy()
{
  enemy.SetActive(true); // 显示敌人
}

当运行时，会报错。原因是enemy没有引用对象，即enemy是空的！

究竟是哪一步出错了？

如果你鼠标悬浮在GameObject.Find()方法上，或者选中它按下F12查看定义，会了解到这个方法仅能找到场景中Active的对象，找不到隐藏的对象！

二、一种解决方式

我可以不使用API获取对象，直接在Inspector面板中选中这个GameObject enemy成员，将场景中的Enemy对象赋予它，确保它不为空即可。

总结

总之，就是不用API，靠自己手动把面板对象拖拽到脚本的成员位置上。
